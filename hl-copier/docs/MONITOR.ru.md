# Монитор — как наблюдаем за трейдерами

> Discovery-часть сервиса: **Монитор** (следить за выбранными адресами) →
> **Копир** (исполнять, см. [COPIER-CORE.md](COPIER-CORE.md)).

```
Монитор (следить, алерты)  ──►  Копир (исполнять)
   ↑ Hyperliquid WS+опрос        ↑ Binance
```

Кого копировать — выбираешь вручную (напр. по внешнему дашборду), заводишь адрес в монитор.

---

## Что делает
Следит за списком адресов на Hyperliquid и **шлёт алерты в Telegram**, когда наблюдаемый
открывает/доливает/сокращает/закрывает/разворачивает позицию или меняет плечо. Плюс держит
данные для вкладки «Монитор» в UI (позиции, эквити, ROI).

## Два механизма (мгновенно + надёжно)
| Канал | Что даёт | Когда |
|---|---|---|
| **WebSocket** (`userFills` цели) | мгновенный алерт на сделку | как только трейдер сделал сделку |
| **Опрос** (раз в `monitor_interval_sec`, 30с) | данные для UI + **backstop-алерты** | страховка, если WS что-то упустил |

Алерты идут мгновенно из WS; опрос сравнивает снимок позиций и шлёт алерт, **только если WS
его не прислал** (дедуп по `(адрес, монета, действие)` в окне `MON_DEDUP_SEC`). Так нет дублей,
но и пропусков из-за обрыва WS тоже нет. WS — устойчивый (авто-реконнект, см. COPIER-CORE §7).

## Что ловит
`ОТКРЫЛ` · `ДОЛИЛ` · `СОКРАТИЛ` · `ЗАКРЫЛ` · `РАЗВЕРНУЛ` · `сменил плечо`.

## Формат алерта
```
👁 Наблюдаемый · 58bro
0x1111111111111111111111111111111111111111
────────────
🔴 BTC (Cross · Short · Долив)
• Размер: -28.5446 → -29.0369 (+1.72%)
• Объём ордера: $32.9K
• Ср. цена: $66,850
• Экспозиция: 35.9% · 5x
📅 2026-06-15 13:21:06 UTC
```
Имя берётся из метки, которую ты задал адресу. Backstop-алерты (по опросу) помечены,
чтобы было видно, что пришли не по WS.

## Связка с копиром
- **«→ В копир»** на адресе = сделать его **целью копирования** (работаем с одним адресом).
- Скопированный адрес помечается в мониторе как «сейчас копирую».
- **Колокол** (`alerts`) — включить/выключить алерты по конкретному адресу.

## Настройки (`config/config.json`)
| Ключ | Назначение | Типичное |
|---|---|---|
| `monitors[]` | список: `{address, name, alerts}` | до ~10–15 адресов |
| `monitor_interval_sec` | период опроса (UI + backstop) | 30 |
| `monitor_min_delta_pct` | порог backstop-алерта (% изменения позы) | 5 |

---

## Полный цикл
```
[Монитор]  следит за сделками адреса, алерты в Telegram (WS + backstop)
   │  «→ В копир» → «Старт LIVE»
   ▼
[Копир]  реконсиляция позиции под наш эквити с кэпами/риском (COPIER-CORE.md)
```
